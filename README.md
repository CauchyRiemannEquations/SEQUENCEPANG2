# 시퀀스팡2 · SEQUENCEPANG 2

등차·등비수열을 연결해 별을 모으는 모바일 퍼즐입니다. 총 50스테이지이며 최대 보드는 5×5입니다.

## 실행과 검증

```sh
npm start
npm test
```

Node 20 이상을 사용합니다. `dist/`는 별도 빌드 없이 정적 호스팅할 수 있습니다. ES 모듈이므로 HTML 더블 클릭 대신 HTTP 서버로 실행합니다.

## 화면과 조작

- 제공된 시퀀스팡2 로고를 메인과 게임 화면에 사용합니다. 짙은 초록 배경, 금색 프레임, 크림색 타일, 주황색 선택 강조를 적용했습니다.
- 메인에는 시작하기, 플레이 방법, 설정, `cremationmath@gmail.com` 문의 링크가 있습니다. 문의 버튼은 플레이 방법과 같은 줄에 있으며 이메일 주소는 화면에 표시하지 않습니다. 스테이지 선택 메뉴는 없습니다.
- 모바일에서는 로고와 여백을 줄이고 게임판을 현재 화면 높이와 튜토리얼 높이에 맞춥니다. 매우 낮은 가로 화면에서는 터치 영역을 유지하며 스크롤을 허용합니다.
- 설정의 게임 초기화는 확인창을 거쳐 완료 기록과 현재 판만 지우며, 효과음 설정은 유지합니다.
- 시작하기는 마지막으로 하던 스테이지를 처음부터 시작하거나 첫 미완료 스테이지로 이동합니다. 기록이 없는 기기는 1번부터 시작합니다.
- 제한 횟수 안에 별 타일만 모두 제거하면 성공합니다. 별 없는 숫자는 남아도 됩니다.
- 이웃한 숫자 3개 이상을 누른 채 연결합니다. 대각선, 꺾인 경로, 역순, 공차 0, 분수 공비도 허용합니다.
- 제거 후 위의 타일이 아래로 내려오며 새 타일은 생기지 않습니다. 잘못된 연결은 이동 횟수를 소모하지 않습니다.
- 초반 스테이지의 설명을 유지합니다. 플레이 방법에서 등차·등비 드래그와 낙하 애니메이션을 볼 수 있습니다. 시범을 멈출 수 있고, 동작 줄이기 설정에서는 정지된 설명을 제공합니다.
- 실패 시 같은 판을 재도전합니다. 플레이 중 다시하기는 설정 안에 있습니다. 되돌리기·힌트·아이템은 없습니다.
- 숫자 타일과 도움말 시범에는 둥글고 두툼한 Bagel Fat One 글꼴을 사용합니다. 플레이 방법은 메인과 게임 화면에서 열며 설정에는 중복 배치하지 않습니다.
- 키보드: Tab으로 숫자에 이동하고 Space로 선택한 후 선택 완료를 누릅니다. Escape는 선택을 취소합니다.

## 진행 저장

기기 내 localStorage만 사용하며 서버에 저장하거나 다른 기기로 동기화하지 않습니다. 현재 스테이지의 키만 저장하며 보드 상태·남은 횟수·연결 이력은 저장하지 않습니다. 메인에서 다시 시작하거나 새로고침 후 돌아오면 같은 스테이지의 원래 판과 전체 이동 횟수로 시작합니다. 기존 v1 저장 데이터는 스테이지 키만 이전하며 완료 기록은 유지합니다. 완료한 판은 다음 미완료 스테이지로 이어집니다. 저장소를 사용할 수 없어도 게임은 실행됩니다.

- `sequencepang2-active-v1`: 마지막 스테이지 키 (내용 형식 v2, 과거 연결 이력은 제거)
- `sequenstar-campaign-v2`: 기존 사용자 완료 기록과의 호환성을 위해 유지한 내부 키 (화면에는 이전 이름을 사용하지 않음)
- `sequencepang2-v1`: 초창기 기록 읽기 지원
- `sequencepang2-sound`: 효과음 설정. 이전 효과음 키도 읽습니다.

## 캠페인

1–30번의 숫자, 별, 제한 횟수, 고정 키를 유지합니다.

| 구간 | 구성 |
| --- | --- |
| 1–10 | 규칙 입문 8판, 두 번 연결하는 연습 2판 |
| 11–16 | 최소 3수, 순서와 낙하 |
| 17–24 | 최소 4수, 준비 수와 복합 연결 |
| 25–30 | 5×5, 최소 5수 |
| 31–50 | 5판씩 네 묶음: 4×4 3수 → 4×4 4수 → 5×5 4수 → 5×5 5수 → 구간 난제 |

31·36·41·46번은 작은 판에서 여러 첫 수로 풀리고, 35·40·45·50번은 성공 가능한 첫 연결이 하나인 판입니다. 난이도 지표는 사람의 체감 순서를 완전히 보장하지 않으므로 플레이 반응에 따라 조정할 수 있습니다. 51–100번과 새로운 판 모양은 후속 계획입니다.

`npm run generate:campaign`은 11–30번, `npm run generate:expansion`은 31–50번을 고정 시드로 재생성합니다. 퍼즐은 플레이 중 생성하지 않습니다. 개발용 데이터에 정답 경로와 검증 지표를 보관합니다.

## 주요 파일

- `dist/app.js`, `index.html`, `style.css`: 화면, 드래그, 도움말과 애니메이션
- `dist/sequencepang2-logo-v2.jpg`: 사용자가 제공한 새 로고. 전달 파일은 알파 채널 없는 JPEG이므로 CSS screen 합성으로 검은 바탕을 배경에 통합하며 원본 픽셀은 변경하지 않습니다.
- `dist/engine.js`, `session.js`: 수열 규칙, 낙하, 게임 상태
- `dist/progress.js`: 완료 기록 이전, 스테이지 저장 및 처음부터 재시작
- `dist/levels.js`, `campaign-data.js`, `expansion-data.js`: 50개 고정 퍼즐
- `tests/`: 전체 퍼즐 해결 가능성, 최소 수, 저장·복원·실패·재시작 검증

전체 50판의 중도 종료 후 처음부터 재시작, 이전 저장 형식 이전, 잘못된 저장 데이터 처리와 완료 기록 유지도 검사합니다. 모바일 실기기의 터치 검사는 별도입니다.
