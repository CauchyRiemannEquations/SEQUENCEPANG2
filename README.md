# 시퀀스타 · SEQUENSTAR

애플망고와 별을 테마로 한 수열 퍼즐. 기존 SEQUENCEPANG2 프로젝트의 새 게임 이름입니다.

짙은 초록색 배경과 애플망고 타일, 금빛 별을 사용하는 모바일 우선 퍼즐 게임입니다.

## 실행

Node.js 20 이상에서 추가 설치 없이 실행합니다.

```sh
npm start
```

브라우저에서 http://localhost:3000 에 접속합니다. `dist/` 폴더를 그대로 정적 웹 호스팅에 올릴 수도 있습니다. ES 모듈을 사용하므로 HTML 파일을 직접 더블 클릭하는 대신 HTTP 서버를 이용하세요.

## 규칙

- 이웃한 숫자 3개 이상을 등차 또는 등비수열로 연결합니다. 대각선과 역순도 허용합니다.
- 제한된 유효 이동 횟수 안에 별 타일을 모두 제거하면 성공합니다.
- 제거 후 타일은 아래로 내려오며 새 타일은 보충되지 않습니다.
- 시간제한 없이 생각할 수 있습니다. 잘못된 연결은 횟수를 소모하지 않습니다.
- 힌트·되돌리기·아이템은 없습니다. 오른쪽 위 설정 메뉴에서 다시하기·메인화면·효과음·게임 방법을 이용합니다.
- 횟수를 모두 쓰거나 연결 가능한 수열이 없으면 실패하며, 결과 화면에서 같은 스테이지에 재도전할 수 있습니다.
- 3×3, 4×4, 5×5 보드의 50개 스테이지, 5개 챕터, 선택형 효과음, 기기 내 완료 기록을 제공합니다.

메인화면에서 시작하기·스테이지 선택·게임 방법을 이용합니다. 플레이 중 메인으로 돌아가면 현재 판을 유지하고 계속하기로 복귀합니다.
현재 판은 같은 페이지가 열려 있는 동안 유지됩니다. 새로고침하면 완료 기록만 유지됩니다.

터치 또는 마우스로 드래그합니다. 키보드는 Tab으로 이동하고 Space로 타일을 선택한 후 ‘선택 완료’를 누릅니다. Escape는 선택을 취소합니다.

## 구성

- `dist/index.html`, `dist/style.css`: 반응형 게임 화면
- `dist/app.js`: 메인화면, 조작, 결과 화면, 저장, 소리
- `dist/engine.js`: 수열 판정, 인접성, 제거/낙하, 풀이 탐색
- `dist/session.js`: 성공·실패·재도전 상태 전이
- `dist/levels.js`: 입문 8판, 연습 2판, 챕터 및 고정 스테이지 식별자
- `dist/campaign-data.js`: 사전 검증된 복합 퍼즐 20판 (11–30)
- `dist/expansion-data.js`: 5판 주기로 난이도를 조절한 추가 퍼즐 20판 (31–50)
- `dist/progress.js`: 완료 기록 저장과 기존 8판의 기록 이전
- `dist/mango-v2.png`: 애플망고와 별 마스코트
- `scripts/generate-campaign.mjs`: 재현 가능한 오프라인 퍼즐 후보 생성 및 검증
- `server.mjs`: 로컬 정적 파일 서버
- `tests/engine.test.mjs`: 핵심 규칙 및 전체 스테이지 해결 가능성 검증
- `tests/session.test.mjs`: 실패, 입력 차단, 재도전 복원 및 마지막 이동 성공 검증
- `tests/campaign.test.mjs`: 퍼즐 의도, 최소 이동 수, 기록 이전, 설정의 다시하기 검증

## 검증

```sh
npm test
```

50판의 해결 가능성, 11–50번의 정확한 최소 이동 수, 가능한 모든 첫 수의 성공/실패, 낙하 후에만 이어지는 수열, 저장 기록 이전, 재시작을 검사합니다. 모든 새 퍼즐의 검증된 풀이를 실제 `GameSession.play`로 재생하여 마지막 이동에서 클리어되는지도 확인합니다. 50판 확장은 109개 자동 테스트와 기존 30판 데이터 비교를 통과했습니다. 이번 환경의 브라우저 보안 정책으로 로컬 화면 확인은 완료하지 못했습니다. 5개 챕터 탭의 모바일 실기기 표시와 체감 난이도는 추가 플레이 확인이 필요합니다.

## 캠페인 구성

| 챕터 | 스테이지 | 목적 |
| --- | --- | --- |
| 첫 번째 별 | 1–10 | 규칙 입문 8판 + 두 번 연결하는 연습 2판 |
| 망고 숲 | 11–16 | 최소 3수: 첫 수 선택, 준비 수, 낙하 후 연결 |
| 망고 숲 | 17–20 | 최소 4수: 여러 차례 낙하와 연결 순서 조합 |
| 별의 궤도 | 21–24 | 5×5에서 최소 4수로 복합 연결 |
| 별의 궤도 | 25–30 | 5×5에서 최소 5수로 별 수집과 준비 수 조합 |

1–30번은 이전 버전과 동일하게 유지합니다. 11번부터는 새로운 퍼즐이며, 단순히 횟수만 줄이지 않았습니다. 모든 첫 수를 조사하여 성공 가능한 첫 수는 1–3가지이면서 전체 첫 수의 30% 이하인 판만 채택했습니다. 일부 판은 별 없는 수열로 시작해야 하며, 등차·등비 혼합도 포함합니다. 검증 풀이에서는 11–16번은 최소 한 번, 17–30번은 최소 두 번 이상 낙하로 새로운 연결이 생깁니다. 역방향이나 같은 타일을 지우는 경로는 같은 첫 수로 계산합니다.

`npm run generate:campaign`은 고정 시드로 복합 퍼즐 20판을 재생성합니다. 생성기는 더 짧은 모든 풀이와 모든 첫 수를 조사하고, 탐색 한도에 걸린 후보는 채택하지 않습니다. 퍼즐은 플레이 중 생성하거나 탐색하지 않습니다. `solveDetailed`는 해결·불가능·탐색 한도 초과를 구분하며, 복합 퍼즐 검증 테스트는 더 큰 탐색 예산을 사용합니다.

기존 입문 8판과 원작 1–2번은 키와 완료 기록을 유지합니다. 교체된 퍼즐은 `complex-v3-*`라는 새 키를 사용하므로 예전 쉬운 판의 완료 기록이 새 퍼즐을 클리어한 것으로 표시되지 않습니다.

## 31–50 확장

첫 공개 분량은 50판이며, 6×6·아이템·특수 타일은 없습니다. 네 묶음(31–35, 36–40, 41–45, 46–50)에 다음 흐름을 반복합니다.

| 묶음 내 순서 | 보드 | 최소 이동 | 구성 |
| --- | --- | --- | --- |
| 1 | 4×4 | 3 | 숨 돌리기: 성공 가능한 첫 수 2개 이상 |
| 2 | 4×4 | 4 | 등차와 등비를 함께 쓰는 검증 풀이 |
| 3 | 5×5 | 4 | 별 없는 준비 수로 시작해야 하는 판 |
| 4 | 5×5 | 5 | 성공 가능한 첫 수 최대 2개 |
| 5 | 5×5 | 5 | 성공 가능한 첫 수 1개, 풀이에서 낙하로 새 연결 최소 3회 |

31–40은 ‘별의 갈림길’, 41–50은 ‘별의 정상’입니다. 난이도는 최소 수, 성공 가능한 첫 수 비율, 준비 수와 낙하를 기준으로 배치했습니다. 이 수치는 사람의 체감 난이도 순서를 보장하지 않으며 플레이 반응에 따라 조정할 수 있습니다. 모든 정답과 좌표는 개발용 데이터에 보관하되 게임에 힌트 버튼을 추가하지 않습니다.

`npm run generate:expansion`으로 고정 시드의 20판을 재생성합니다. 모든 후보를 검증한 뒤에만 데이터 파일을 교체하므로 생성 중단 시 기존 판을 보존합니다. 기존 생성 명령 `generate:campaign`은 11–30번만 담당합니다.

기존 1–30의 완료 기록은 그대로 유지하며, 모두 완료한 사용자는 시작하기에서 31번으로 이어집니다. 추가 판은 `expansion-v1-*` 키를 사용합니다. 이후 51–100은 10판씩 추가하는 계획이며 이번 배포에는 포함하지 않습니다.

## 데이터

완료한 스테이지는 브라우저 localStorage에만 저장됩니다. 계정·서버·분석 도구를 사용하지 않으며, 다른 기기와 기록이 동기화되지 않습니다. 배포 플랫폼의 접근 인증은 게임과 별개입니다.
기존 `sequencepang2-v1` 기록을 해당 원본 퍼즐의 고정 키로 읽어오고, 새 완료 기록은 `sequenstar-campaign-v2`에 저장합니다. 기존 저장 데이터는 삭제하지 않습니다.
