# 시퀀스타 · SEQUENSTAR

애플망고와 별을 테마로 한 수열 퍼즐. 기존 SEQUENCEPANG2 프로젝트의 새 게임 이름입니다.

짙은 초록색 배경과 애플망고 타일, 금빛 별을 사용하는 모바일 우선 퍼즐 게임입니다.

## 실행

Node.js 20 이상에서 추가 설치 없이 실행합니다.

```sh
npm start
```

브라우저에서 http://localhost:3000 에 접속합니다. `dist/` 폴더를 그대로 정적 웹 호스팅에 올릴 수도 있습니다. ES 모듈을 사용하므로 HTML 파일을 직접 더블 클릭하는 대신 HTTP 서버를 이용하세요.

## 규칙

- 이웃한 숫자 3개 이상을 등차 또는 등비수열로 연결합니다. 대각선과 역순도 허용합니다.
- 제한된 유효 이동 횟수 안에 별 타일을 모두 제거하면 성공합니다.
- 제거 후 타일은 아래로 내려오며 새 타일은 보충되지 않습니다.
- 시간제한 없이 생각할 수 있습니다. 잘못된 연결은 횟수를 소모하지 않습니다.
- 힌트·되돌리기·아이템은 없습니다. 오른쪽 위 설정 메뉴에서 다시하기·메인화면·효과음·게임 방법을 이용합니다.
- 횟수를 모두 쓰거나 연결 가능한 수열이 없으면 실패하며, 결과 화면에서 같은 스테이지에 재도전할 수 있습니다.
- 3×3, 4×4, 5×5 보드의 30개 스테이지, 3개 챕터, 선택형 효과음, 기기 내 완료 기록을 제공합니다.

메인화면에서 시작하기·스테이지 선택·게임 방법을 이용합니다. 플레이 중 메인으로 돌아가면 현재 판을 유지하고 계속하기로 복귀합니다.
현재 판은 같은 페이지가 열려 있는 동안 유지됩니다. 새로고침하면 완료 기록만 유지됩니다.

터치 또는 마우스로 드래그합니다. 키보드는 Tab으로 이동하고 Space로 타일을 선택한 후 ‘선택 완료’를 누릅니다. Escape는 선택을 취소합니다.

## 구성

- `dist/index.html`, `dist/style.css`: 반응형 게임 화면
- `dist/app.js`: 메인화면, 조작, 결과 화면, 저장, 소리
- `dist/engine.js`: 수열 판정, 인접성, 제거/낙하, 풀이 탐색
- `dist/session.js`: 성공·실패·재도전 상태 전이
- `dist/levels.js`: 입문 8판, 원작 8판, 챕터 및 고정 스테이지 식별자
- `dist/campaign-data.js`: 사전 검증된 새 퍼즐 14판
- `dist/progress.js`: 완료 기록 저장과 기존 8판의 기록 이전
- `dist/mango-v2.png`: 애플망고와 별 마스코트
- `scripts/generate-campaign.mjs`: 재현 가능한 오프라인 퍼즐 후보 생성 및 검증
- `server.mjs`: 로컬 정적 파일 서버
- `tests/engine.test.mjs`: 핵심 규칙 및 전체 스테이지 해결 가능성 검증
- `tests/session.test.mjs`: 실패, 입력 차단, 재도전 복원 및 마지막 이동 성공 검증
- `tests/campaign.test.mjs`: 퍼즐 의도, 최소 이동 수, 기록 이전, 설정의 다시하기 검증

## 검증

```sh
npm test
```

30판의 해결 가능성, 후반부의 최소 이동 수, 준비 수가 반드시 필요한 조건, 저장 기록 이전, 다시하기를 포함해 58개 테스트를 실행합니다. Chromium에서 전체 30판 드래그 클리어와 키보드 조작, 설정, 재시작, 이어하기, 320/390/1440px 화면을 확인했습니다. 모바일 실기기 터치는 별도로 확인해야 합니다.

## 캠페인 구성

| 챕터 | 스테이지 | 목적 |
| --- | --- | --- |
| 첫 번째 별 | 1–8 | 등차·역순·대각선·꺾인 경로·등비·같은 숫자·긴 연결 |
| 망고 숲 | 9–20 | 기존 8판과 올바른 첫 수를 골라야 하는 새 퍼즐 4판 |
| 별의 궤도 | 21–30 | 별 없는 수열을 먼저 지워야 풀리는 2~3수 퍼즐 |

모든 스테이지는 선택해서 플레이할 수 있습니다. 입문 구간의 안내는 규칙 설명이며 정답 경로나 타일을 표시하지 않습니다. 기존 스테이지 1–8은 숫자·별·제한 횟수를 유지한 채 9–16으로 이동했습니다.

`npm run generate:campaign`은 고정 시드로 새 퍼즐 14판을 재생성합니다. 생성기는 최소 이동 수와 모든 가능한 첫 수를 검사하고, 탐색 한도에 걸린 후보는 채택하지 않습니다. 퍼즐은 플레이 중 생성하지 않습니다. `solveDetailed`는 해결·불가능·탐색 한도 초과를 구분합니다. 새 기획 의도와 사람의 체감 난이도는 추가 플레이 테스트로 조정해야 합니다.

## 데이터

완료한 스테이지는 브라우저 localStorage에만 저장됩니다. 계정·서버·분석 도구를 사용하지 않으며, 다른 기기와 기록이 동기화되지 않습니다. 배포 플랫폼의 접근 인증은 게임과 별개입니다.
기존 `sequencepang2-v1` 기록을 해당 원본 퍼즐의 고정 키로 읽어오고, 새 완료 기록은 `sequenstar-campaign-v2`에 저장합니다. 기존 저장 데이터는 삭제하지 않습니다.
