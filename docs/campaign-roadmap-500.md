# 시퀀스팡2 500단계 장기 캠페인 로드맵

> 상태: 장기 기획안  
> 기준일: 2026-10-03  
> 현재 구현 범위: 1–100  
> 목표: 스토어 게시와 장기 업데이트를 고려해 500단계까지의 방향을 미리 고정한다.

## 핵심 원칙

시퀀스팡2는 새 규칙을 계속 덧붙이는 게임이 아니라, **등차·등비 수열 + 연결 순서 + 낙하**라는 기본 규칙을 점점 깊게 사용하는 퍼즐을 목표로 한다.

- 5×5보다 큰 보드는 기본적으로 사용하지 않는다.
- 큰 판 자체를 난이도 상승 수단으로 반복하지 않는다.
- 새 기믹은 설명이 짧고 시각적으로 즉시 이해되어야 한다.
- 한 스테이지에 모든 기믹을 넣지 않는다.
- 350단계 이후에는 신규 핵심 기믹 추가를 원칙적으로 중단한다.
- 후반으로 갈수록 "더 많은 규칙"보다 "더 깊은 조합"으로 난도를 만든다.
- 10단계 안에는 도입 → 응용 → 숨 고르기 → 복합 → 고비의 리듬을 둔다.
- 모바일 터치 오동작, 작은 터치 영역, 판독성 저하는 난이도로 취급하지 않는다.
- 각 신규 기믹은 소수의 프로토타입으로 재미와 조작성을 검증한 뒤 확정한다.

## 전체 구조

| 단계 | 핵심 경험 | 신규 요소 |
| --- | --- | --- |
| 1–50 | 기본 수열과 낙하 | 등차·등비, 연결 순서, 낙하 |
| 51–100 | 판 구성의 변화와 심화 | 현재 구현된 100단계 캠페인 |
| 101–120 | 숫자를 남긴다 | 서리 블록 |
| 121–150 | 위치를 남긴다 | 고정 블록 |
| 151–200 | 멀리 영향을 준다 | 연동 블록 |
| 201–250 | 숫자를 바꾼다 | +1 / -1 변환 |
| 251–300 | 숫자를 추론한다 | ? 미지수 |
| 301–350 | 두 상태를 운용한다 | 양면 블록 |
| 351–400 | 두 기믹을 조합한다 | 신규 기믹 없음 |
| 401–450 | 작은 판에서 깊게 읽는다 | 신규 기믹 없음 |
| 451–500 | 시퀀스팡의 기본기로 회귀한다 | 클래식/마스터 퍼즐 |

# 101–150: 남기는 퍼즐

## 101–120 — 서리 블록

### 규칙

서리 블록은 숫자를 가리지 않는다. 일반 숫자처럼 수열 판정에 참여하지만 첫 번째 유효 연결에서는 숫자가 사라지지 않고 **서리만 깨진다**. 두 번째로 실제 제거될 때 별도 함께 수집한다.

핵심은 같은 숫자를 두 번 활용하는 것이다.

### 배치

- **101–105:** 서리 1개. 첫 연결에서 살아남는다는 규칙 학습.
- **106–110:** 서리를 벗긴 숫자를 다른 수열에서 재사용.
- **111–115:** 여러 서리 중 어떤 숫자를 남길지 선택.
- **116:** 서리 없는 작은 판으로 숨 고르기.
- **117–119:** 서리 + 낙하 + 등차/등비 전환.
- **120:** 서리 챕터 종합 고비.

서리는 기본 1–3개만 사용한다. 단순히 같은 경로를 두 번 긋는 반복 작업이 되면 기믹을 재설계하거나 사용량을 줄인다.

## 121–150 — 고정 블록

### 규칙

고정 블록은 정상적으로 수열에 참여하지만, 아래 칸이 비어도 떨어지지 않는다. 해당 숫자가 실제로 제거되면 그때 위쪽 블록이 낙하한다.

핵심은 숫자뿐 아니라 **위치를 남기는 것**이다.

### 배치

- **121–125:** 고정 블록 1개 입문.
- **126:** 일반판 숨 고르기.
- **127–130:** 고정 블록 2개, 제거 순서 선택.
- **131–135:** 고정 때문에 생기는 공중 숫자와 단절된 열 활용.
- **136:** 작은 일반판.
- **137–140:** 고정 + 낙하 심화.
- **141–145:** 서리 × 고정의 첫 결합.
- **146:** 짧고 시원한 3×4 계열 퍼즐.
- **147–149:** 변형 판 + 낙하 + 서리/고정.
- **150:** "무엇을 언제 남길 것인가"를 묻는 완결 퍼즐.

---

# 151–200: 연동 블록

## 규칙

같은 표식의 연동 블록 두 개가 한 쌍이다. 한쪽 연동 블록이 수열에 포함되어 **실제로 제거되면**, 짝도 함께 제거된다.

핵심은 한쪽의 선택이 다른 열의 낙하까지 바꾸는 **원격 영향**이다.

서리와 결합할 경우 연동 효과를 받은 서리 블록은 한 번에 사라지지 않고 서리만 벗겨지는 규칙을 우선안으로 한다.

## 배치

- **151–160 — 연동 입문**
  - 한 쌍부터 시작.
  - 연동 제거 뒤 반대쪽에서 다음 수열이 만들어지는 구조.
  - 160은 연동 기본 종합.
- **161–170 — 원격 낙하**
  - 한쪽 수열이 다른 열을 무너뜨리는 문제.
  - 화면 전체를 하나의 판으로 읽게 한다.
- **171–180 — 연동 × 고정**
  - 양쪽 열의 낙하 결과가 다르게 만들어지는 구조.
- **181–190 — 연동 × 서리**
  - 원격 효과로 서리를 벗기고 이후 다시 활용.
- **191–200 — 연동 종합**
  - 새 규칙 없이 대표 조합을 정리.
  - 196에는 짧은 휴식 스테이지.
  - 200은 연동 → 낙하 → 고정/서리 → 다음 수열이 이어지는 완결 퍼즐.

# 201–250: 변환 블록

변환은 강력하고 계산 부담도 커질 수 있으므로 200단계 이후에 도입한다.

## +1 / -1 변환

변환 블록은 첫 번째 유효 사용에서 사라지는 대신 숫자가 변한다.

예:

- `4⁺` → 첫 사용 후 `5`
- `6⁻` → 첫 사용 후 `5`

변환된 숫자는 이후 일반 숫자로 취급한다.

핵심은 **현재 수열과 다음 수열을 동시에 보는 것**이다.

## 배치

- **201–210:** +1만 사용.
- **211–220:** -1 도입.
- **221–230:** +1 / -1 혼합.
- **231–240:** 변환 + 낙하 + 변형 판.
- **241–249:** 변환과 기존 기믹 하나만 조합.
- **250:** 변환 챕터 완결.

초기에는 한 판의 변환 블록 수를 적게 유지한다. 단순 암산량 증가가 난이도의 중심이 되지 않도록 한다.

---

# 251–300: 미지수 블록

## 규칙

`?` 블록은 숨겨진 고정 숫자를 맞히는 블록이 아니다. 플레이어가 선택한 수열이 성립하도록 필요한 숫자로 **연결 순간 결정**된다.

예:

`3 - ? - 9`를 등차로 연결하면 `? = 6`.

초반에는 가능한 값이 하나뿐인 문제만 사용한다. 후반에는 등차/등비 중 어느 해석을 선택하느냐에 따라 값이 달라지는 문제를 제한적으로 허용한다.

핵심은 **숫자를 계산하는 것보다 수열의 구조를 읽는 것**이다.

## 배치

- **251–260:** 가운데 미지수, 등차 중심.
- **261–270:** 등비까지 확장.
- **271–280:** 첫항/끝항이 미지수인 형태.
- **281–290:** 미지수 + 낙하.
- **291–299:** 미지수 + 기존 기믹 하나.
- **300:** 미지수 챕터 보스.

---

# 301–350: 양면 블록

## 규칙

양면 블록은 두 숫자 상태를 가진다.

예: `3↔6`

처음에는 3으로 수열에 참여한다. 첫 사용 후 제거되지 않고 6으로 뒤집힌다. 두 번째 상태에서 다시 유효하게 사용하면 실제로 제거된다.

서리와 달리 **같은 숫자가 남는 것이 아니라 다른 숫자로 남는다**는 점이 핵심이다.

## 배치

- **301–310:** 단순한 양면 숫자.
- **311–320:** 언제 뒤집을지 선택.
- **321–330:** 양면 + 낙하.
- **331–340:** 양면 + 고정 또는 연동.
- **341–349:** 양면 + 변환.
- **350:** 양면 챕터 완결.

350 이후에는 신규 핵심 블록을 추가하지 않는 것을 기본 원칙으로 한다.

---

# 351–400: 두 기믹의 조합

새 규칙 없이 이미 배운 요소의 상호작용을 깊게 만든다.

- **351–360:** 서리 × 고정
- **361–370:** 연동 × 변환
- **371–380:** 미지수 × 고정
- **381–390:** 미지수 × 양면
- **391–399:** 플레이테스트에서 가장 재미있었던 조합의 변주
- **400:** 2기믹 마스터 스테이지

기본적으로 한 판의 핵심 기믹은 최대 2종을 유지한다.

---

# 401–450: 작은 판, 깊은 상태 변화

난도를 "큰 판 + 많은 특수블록"으로 올리지 않는다. 오히려 3×4, 4×4처럼 작은 판에서 한 수의 의미를 크게 만든다.

- **401–410:** 3×4 정밀 퍼즐
- **411–420:** 4×4 정밀 퍼즐
- **421–430:** 직사각형 + 2~3기믹
- **431–440:** 계단형/변형 판 + 2~3기믹
- **441–449:** 각 기믹의 대표 최고난도
- **450:** 종합 마스터 보스

한 판의 핵심 기믹은 최대 3종을 권장한다. 판독성이 떨어지면 2종으로 되돌린다.

---

# 451–500: 클래식 회귀와 마스터 퍼즐

마지막 50단계에서는 새 블록을 추가하지 않는다. 플레이어가 450단계까지 배운 내용을 바탕으로 **시퀀스팡의 기본 규칙 자체가 얼마나 깊은지** 보여준다.

## 451–460 — 클래식 리믹스

특수블록을 거의 쓰지 않고 4×4 중심의 고난도 수열 퍼즐을 만든다.

목표 감정은 "특수 규칙이 없는데 왜 어렵지?"이다.

## 461–470 — 낙하 마스터

연결 순서와 낙하만으로 깊은 문제를 만든다. 시퀀스팡2의 근본 규칙을 다시 전면에 둔다.

## 471–480 — 변환 마스터

+1/-1, 양면 등을 절제해서 사용한다. 숫자 상태는 깊게 변하지만 판 자체는 작게 유지한다.

## 481–490 — Best Mechanics

각 기믹의 대표적인 재미를 다시 보여 주는 보스 러시 구간.

예시:

- 481 서리
- 482 고정
- 483 연동
- 484 변환
- 485 미지수
- 486 양면
- 이후에는 가장 성공적인 조합을 재사용

## 491–499 — 제작자 퍼즐

각 스테이지마다 한 문장으로 설명 가능한 명확한 설계 의도를 둔다.

예:

- "정답처럼 보이는 첫 수를 먼저 지우면 실패한다."
- "고정 블록 하나를 마지막까지 유지해야 한다."
- "연동 한 번이 판 전체의 낙하를 바꾼다."
- "미지수의 역할을 두 번 다르게 읽어야 한다."

단순히 어려운 문제가 아니라 제작자가 고른 대표 작품처럼 구성한다.

## 500 — 캠페인 피날레

500단계에는 새 규칙을 넣지 않는다.

우선안은 하나의 거대한 판보다 **3개의 작은 미니 퍼즐로 이어지는 특별 스테이지**다.

1. 등차수열 중심
2. 등비수열 중심
3. 지금까지의 대표 기믹을 절제해 조합

마지막 클리어에서는 일반 스테이지보다 강한 별/망고 연출과 함께 500단계 완주를 명확히 축하한다.

# 난이도 및 제작 규칙

## 새 기믹 도입 리듬

신규 기믹이 있는 10단계 묶음은 기본적으로 다음 리듬을 따른다.

1. 1–2번째: 규칙 하나만 보여 주는 도입
2. 3–5번째: 순서 또는 낙하 판단 추가
3. 6번째: 작은 판이나 단순 연결로 숨 고르기
4. 7–9번째: 두 판단의 결합
5. 10번째: 새 설명 없는 종합 고비

## 퍼즐 품질 기준

난이도는 다음을 종합해 판단한다.

- 가능한 첫 연결의 수
- 정답이 아닌 유혹 경로의 강도
- 몇 수 앞까지 낙하를 예상해야 하는지
- 현재 숫자와 다음 상태를 동시에 기억해야 하는지
- 한 번의 선택이 몇 개의 열에 영향을 주는지
- 판의 크기와 시각적 밀도

단순히 이동 횟수, 특수블록 수, 숫자 크기로 난이도를 올리지 않는다.

## 조합 상한

- 101–350: 새 기믹을 학습하는 동안 핵심은 가급적 1–2종.
- 351–400: 핵심 2종.
- 401–450: 최대 3종.
- 451–500: 필요한 만큼 덜어내며 기본 규칙의 깊이를 우선.

# 스토어/업데이트 관점

500단계는 **첫 스토어 출시 때 모두 구현해야 하는 목표가 아니라 장기 콘텐츠 지도**다.

권장 운영 방향:

- 현재 1–100은 안정적인 기반 캠페인으로 유지.
- 신규 구간은 10~50단계 단위로 제작·검증·공개.
- 101 이후 신규 기믹은 프로토타입과 모바일 플레이테스트를 통과한 뒤 구현.
- 업데이트 시 기존 진행 기록과 힌트 데이터를 보존.
- 실제 공개된 마지막 단계까지만 게임 UI에서 노출.
- 미완성 미래 단계나 확정되지 않은 기믹을 인게임에서 과도하게 예고하지 않는다.

로드맵 자체는 500까지 유지하되, 플레이테스트에서 재미가 약한 기믹은 뒤 구간을 억지로 맞추지 않고 교체·축소할 수 있다.

# 한 문장으로 보는 500단계

- **1–100:** 수열과 낙하를 배운다.
- **101–200:** 무엇을 남기고 어디에 영향을 줄지 배운다.
- **201–300:** 숫자를 바꾸고 추론한다.
- **301–350:** 숫자의 상태를 운용한다.
- **351–450:** 배운 규칙을 조합한다.
- **451–500:** 결국 순수한 퍼즐 실력으로 돌아온다.
